# Emotion Detector

A detector that runs on the IBM Watson Natural Language Processing (NLP) library to identify emotions in text.

## Overview

This project uses IBM Watson's NLP capabilities to analyze input text and detect underlying emotions such as joy, sadness, anger, fear, and disgust. It's designed as for academic purpose and can be referenced for educational purpose.

## Features

- Text-based emotion detection
- Powered by IBM Watson NLP
- Simple Flask-based API
- JSON-formatted output for easy integration

## Requirements

- Python 3.7+
- IBM Watson SDK (`ibm-watson`)
- Flask (if using the web interface)

## Installation

```bash
pip install ibm-watson flask requests json
```
